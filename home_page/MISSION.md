# Mission: Build a Web Application While Learning the Full Stack

## Why
Build a real web application as the vehicle for learning Rust, HTML, CSS, and JavaScript together, so each concept is immediately connected to working software.

## Success looks like
- Build and explain an Axum backend with routes and application logic
- Create structured, accessible pages with HTML and style them with CSS
- Add browser-side interaction with JavaScript
- Connect the browser frontend to Rust endpoints and debug the full request/response path

## Constraints
- Learn incrementally inside this repository
- Prefer small working slices over disconnected theory

## Out of scope
- Production infrastructure and advanced framework architecture until the fundamentals are working
