# Full-Stack Rust Web Development Resources

## Knowledge

- [Axum routing documentation](https://docs.rs/axum/latest/axum/routing/)
  Primary API documentation for mapping HTTP methods and paths to Axum handlers. Use for: backend routing.
- [Axum response documentation](https://docs.rs/axum/latest/axum/response/)
  Primary API documentation for converting Rust values into HTTP responses. Use for: HTML, JSON, status codes, and headers.
- [The Rust Programming Language](https://doc.rust-lang.org/book/)
  Official Rust book. Use for: ownership, types, error handling, modules, and async foundations.
- [MDN Web Docs](https://developer.mozilla.org/en-US/docs/Learn_web_development)
  Maintained reference and learning material for HTML, CSS, JavaScript, and browser behavior.

## Wisdom (Communities)

- [Rust Users Forum](https://users.rust-lang.org/)
  Moderated technical community. Use for: Rust design questions and compiler errors that benefit from practitioner feedback.
